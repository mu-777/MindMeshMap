# 実マップのフィクスチャ置き場

このディレクトリに置いた `*.json` は、整列アルゴリズムの評価コーパス（`e2e/lib/layout-cases.mjs`）へ
**グループG「実マップ」として自動的に取り込まれる**。`e2e/layout-quality.mjs` の検証対象になり、
`node scripts/layout-contact-sheet.mjs` のコンタクトシートにも並ぶ。

## 追加のしかた

1. アプリでマップを開き、ファイルメニューから **JSONエクスポート** する
   （出力はマップ全体のJSON。`src/utils/exportImport.ts` 参照）
2. 出力されたファイルをこのディレクトリに置く。ファイル名がケースID（`g-<ファイル名>`）になるので、
   `deep-tree.json` のように内容が分かる短い名前にする

合成ケース（グループA〜F）は軸に沿って機械的に作ったもので、現実のマップの形からは外れる。
**実際に自分が使っているマップを数枚置いておくのが、いちばん費用対効果の高い追加**になる。

## 注意

- ここのファイルはgit管理下に入る（＝リポジトリに公開される）。**個人的な内容・見せたくない
  内容のマップは置かない**こと。構造だけを見たい場合は、ノードの `content` を空文字にするか
  ダミーの文字列へ置き換えてから置くとよい（整列アルゴリズムはノードの `width`/`height` しか
  見ておらず、`content` の中身は結果に影響しない）
- ノードに `width`/`height` が入っていない場合は既定サイズ（180×60）として扱われる。実際の
  アプリは画面上の実測サイズを使う（`useAutoLayout.ts`）ため、改行の多いマップを再現したい
  場合は手で `width`/`height` を書き足すと現実に近くなる
- `nodes` / `edges` を持たないJSONは読み飛ばされる
